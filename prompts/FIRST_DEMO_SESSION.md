# 小克 × Quest：第一個展示 session

請在我的 Mac 上實際跑通 https://github.com/pcpcchen-coder/ChatGPTinQUEST 的第一個展示。
本輪只做 docs/05-first-demo.md 的六步，不擴充其他需求。

先檢查執行環境是否真的在 Mac 且能接本機網路。讀 repo 文件與當前官方 Figmin MCP help。若沒有 checkout，clone；已有則保留未提交變更。確認 uv 存在，再執行 scripts/start-demo-mac.sh；若缺少 uv，依官方 macOS 文件安裝適用版本。現有同名 MCP 設定衝突要檢查，不直接覆蓋。需要重啟客戶端時明確告知這一步；重啟後繼續 session。

請用繁體中文，稱呼自己「小克」，回覆簡短。先取得真實 Quest／Mac／Figmin 版本。需要我在頭戴裝置按鍵時，一次只告訴我當下要做的事。

連線後：
1. 讀取 Figmin help，依其真實工具名稱加入目前 session、開啟聊天及語音。不要臆造 MCP 工具或參數。
2. 做中文 STT／TTS 往返。文字能操作僅算診斷通過，不算語音完成。
3. 檢查是否能建立、讀回、取得選取物件、變更、保存及載入。如果保存缺工具，要把它當成本輪需解決的缺口；不可跳過卻宣告全通。
4. 等我說「小克，在前方一公尺建立紅色方塊」，建立一個邊長 20 cm 的方塊，名稱 CQ-DEMO-CUBE-01，讀回 ID 與狀態。
5. 等我用手柄選取。讀實際 selected ID。若讀不到，向我說明，修復指向／選取通道；不能用猜測冒充。
6. 我說「把這個放大兩倍，改成藍色」時，將同一個物件每邊改為 40 cm、藍色。保存操作前後值，重試保持 40 cm，防止倍增。
7. 等我抓取移動且放開後，重新讀取真實物件位置與旋轉。
8. 我說「儲存為我的實驗室」時，保存包括手柄移動後的物件狀態。保存成功回執可驗證後才能說「存好了」。
9. 引導我完全退出並重新啟動 Figmin。重新連 session，再載入我的實驗室；讀回核對一個藍色 40 cm 方塊及變換。若原生載入會覆蓋目前其他內容，先確認。
10. 記錄 local-results/first-demo.md，每步附證據；未測填 NOT_RUN，功能缺口填 BLOCKED。不提交私人資料到公開 repo。

優先使用 Figmin 既有功能。只有確認缺口後才補最小 Spatial App；不要自行切到 Unity 重寫。不要購買產品或啟用額外付費服務。每個動作須看到工具成功與狀態讀回；執行器未回覆不能先說完成。若 SDK 欄位不可讀，清楚指出證據缺口並用實機可見結果補驗，不能編數值。

現在請從檢查本機環境開始，持續做到六步有實機結果，或定位出需要我完成的具體装置操作。
